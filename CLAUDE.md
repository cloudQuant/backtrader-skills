# CLAUDE.md

Canonical guidance for Claude Code and other coding agents working on the
`backtrader-skills` repository. `AGENTS.md` is a short pointer for non-Claude hosts.

## What this repository is

An offline, auditable author/review/test product for the cloudQuant Backtrader fork: three
canonical skills (`skills/backtrader-strategy-{author,review,test}`) plus a deterministic
Python CLI (`src/backtrader_skills/`) distributed as a wheel. The controller never imports
candidate code; approved candidates run only in `python -I` child processes.

Key layout: `src/backtrader_skills/` (all deterministic logic), `skills/` (thin canonical
skills), `scripts/` (doctor, manifest/catalog builders, acceptance, eval scorer),
`resources/` (schemas, policies, catalog snapshot), `tests/`, `evidence/`, and
`docs/iterations/` (per-iteration acceptance evidence).

## Verify before and after changes

From the README "Verify the distribution" section; run all of these through conda base.
The source-checkout helpers auto-discover a Backtrader repository only when this repo is
nested below it or next to a sibling directory named `backtrader`:

```bash
python scripts/doctor.py
python scripts/build_manifest.py --check
python scripts/build_catalog.py --check
python -m pytest tests -q
python scripts/run_acceptance.py --matrix all --require-no-mcp --require-no-agent
```

For a checkout anywhere else:

```bash
python scripts/doctor.py --target /path/to/backtrader
python scripts/run_acceptance.py --repository /path/to/backtrader \
  --matrix all --require-no-mcp --require-no-agent
```

Source-backed tests (execution, doctor, acceptance) honor `BT_BACKTRADER_DIR` pointing at
the fork's `backtrader` package directory and auto-skip when the source is absent.

## Distribution manifest rule (IMPORTANT)

`manifest.json` records the hash and size of every distribution-included file (`src/`,
`skills/`, `scripts/`, `resources/`, `host_adapters/`, `evidence/`, plus `README.md`,
`IMPLEMENTATION_REPORT.md`, and `pyproject.toml`).

- After touching any distribution-included file, rebuild once:
  `python scripts/build_manifest.py`.
- `--check` and `--help` are read-only and never modify `manifest.json`; use `--check`
  for routine validation.
- Never hand-edit hashes or entries in `manifest.json`; it must be generated by the script.

## Iteration workflow

- Work is organized in iterations. Plans live in `docs/superpowers/plans/` (agent working
  files under `.superpowers/sdd/`); per-iteration evidence lives in
  `docs/iterations/iteration-<n>-<name>/` with a required `acceptance.md`; `requirements.md`
  and `design.md` are optional per iteration.
- Each iteration follows: plan → TDD (write failing tests first, run them RED) →
  implement to GREEN → review → record acceptance evidence (exact commands and results,
  no fabricated numbers) under `docs/iterations/`.
- Drift-lock tests (`tests/test_skill_reference_contract.py`,
  `tests/test_ci_python_matrix.py`) pin skill docs and CI config to runtime facts; keep
  them GREEN when changing skills or workflows.
- Progressive disclosure: `SKILL.md` files stay at most 60 lines; each reference file at
  most 300 lines.
- Quality gates: `ruff check .`, `black --check .`, `python -m mypy src/backtrader_skills`,
  and at least 80% coverage over `src/backtrader_skills` except the two `python -I` child
  modules (`child_runner.py`, `isolate_entry.py`) (enforced by CI on master).

## Security notes

- Never commit secrets, API keys, or approval tokens. Eval artifacts under
  `evals/transcripts/` and `evals/results/` are gitignored because they may contain
  approval tokens.
- The preview → approve → apply approval-token workflow is a product-level feature. Do
  not weaken its gates (hash binding, 15-minute TTL, single consumption,
  `CONSUMED/REVOKED/EXPIRED` terminal states).
- The controller never imports candidate code. Candidates execute only in `python -I`
  child processes after proving they are unchanged artifacts of an approved
  render/apply. Preserve this invariant in any refactor.
- CI uses only public repositories; no secrets in workflows.
